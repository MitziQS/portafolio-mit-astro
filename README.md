# Mitzi Soria · Portafolio

Portafolio de Mitzi Soria, diseñadora de productos digitales en CDMX.

Sitio: https://mitzisoria.netlify.app/

## Tecnología

- [Astro](https://astro.build/)
- Netlify (se publica desde la rama `main`)

## Comandos

```bash
pnpm install   # instala las dependencias
pnpm dev       # abre el sitio en http://localhost:4321
pnpm build     # compila el sitio en dist/
```

## Dónde está el contenido

- `src/locales/es/common.json`: textos de la home, experiencia y datos de contacto.
- `src/content/projects/`: los casos de estudio, uno por archivo `.md`.
